# 像素小家 Pixel Home

一个在浏览器里玩的像素风小屋经营游戏：赚钱、买家具、装饰房间、养宠物，慢慢从出租小屋住进小别墅。

纯原生 JavaScript + Canvas，无需安装、无需构建、无任何外部资源；手机竖屏和电脑都能玩。

## 玩法
- **点家具**：走过去使用——睡觉恢复精力、吃饭恢复饱腹、看电视/坐沙发提升心情、洗澡恢复清洁。
- **电脑桌**：点它弹出电脑菜单：「接单工作」走过去干活赚钱（消耗精力和饱腹）；「炒股」打开股市；「学习德州扑克」上网课学德扑。电脑停电时用不了。
- **点空地**：自动寻路走过去。**点宠物**：抚摸，培养感情。
- **门口外景**：室内底墙上的门可以出去，走到门口的街道（草地、人行道、马路、自家小屋、市政厅、汉堡店、牌场和街角小公园）。手机上街道比屏幕宽时，镜头会跟着你横向移动。外景里可以点地面走动、点自家小屋回家。外景时商店和建造不可用，宠物留在家里。门前一格要保持通畅，不能摆放会挡住门口的家具。
- **牌场**（街道右侧，墨绿屋顶、霓虹「牌」字，夜里亮灯）：营业 14:00~次日 06:00，玩德州扑克。
  - **第一次进去会被老千戏耍，强行坑走 20% 现金**（街头智慧高会少亏一点；现金为 0 则只被嘲笑）。之后才能正常玩。
  - 三张桌（买入 50 / 200 / 1000），对手是三位风格不同的 AI（松凶、紧凶、跟注站），可随时离桌带走筹码；偶尔有「私局」邀请，可能是陷阱，街头智慧 4 级起能识破。
  - 牌技越高，牌桌辅助越多：2 级显示牌型，4 级起手牌评级，6 级底池赔率，8 级胜率估算。
  - 回家用电脑「学习德州扑克」：6 节课加小测验，每天最多 3 次，涨牌技。
- **技能**（点顶部「技能」按钮）：六项技能靠日常积累经验，每级一点点变强，满级 10 级。点技能可以展开说明。
  - **体能**：打工和电脑工作的精力消耗 -3%/级。
  - **口才**：林小满聊天的正面好感收益 +4%/级；口才 5 级起，聊天多一个选项。
  - **投资**：炒股手续费 -4%/级，3 级起新闻更早，6 级起有情绪指数，9 级起有明日倾向。
  - **牌技**：牌桌辅助随等级解锁（见牌场）。
  - **手艺**：打工和电脑工作收入 +3%/级。
  - **街头智慧**：被骗概率与损失 -4%/级，4 级起能识破牌场私局骗局。
  - 经验来源：打工一班、电脑工作完成各给体能、手艺；林小满聊天给口才。
- **炒股**（电脑菜单→炒股）：城市有 8 只股票（东港货运、霓虹电力、暗巷赌场集团、私货咖啡进口、海岸地产、警用装备、午夜电台传媒、霓虹夜店连锁），可随时买卖，手续费约 1.2%。价格随游戏时间波动，并受城市事件影响（警方扫黑、港口罢工、赌场被查等），新闻有的会提前预告；每个游戏季度派一次息。有走势图、持仓总览和新闻页。
- **汉堡店「林记汉堡」**：点店门会走到店门前打开面板。营业时间 8:00~22:00，夜里打烊只能看菜单。
  - 买汉堡：小汉堡 8 元、芝士汉堡 14 元、套餐 22 元，买完立刻恢复饱腹/心情/精力。
  - 打工一班：约 12 秒（游戏时间照常流逝，打工中不能走动），到手 45 元，消耗精力 20、饱腹 12、心情 3。精力不足 25 或饱腹不足 20 不能接班；每个游戏日最多 3 班。
- **林小满**：汉堡店店主的女儿，白天站在店门口旁边。点她走过去就能聊天，每天有效聊天 2 次；可以送她汉堡（每天 1 次）；「问问她的事」会一段段解锁她的故事，最后一段是她的心事。
- **周慕白（市议员）**：你在这座城里的朋友，开局好感就是「认识」。白天 9:00~17:00 站在**市政厅**门口（点市政厅门或点他都会打开**市政厅面板**）。面板里有城市指数、可推动的项目、礼物清单和聊天故事；他的心事和他父亲的事故，要慢慢问。
- **程念（星河科技数据组）**：傍晚 18:00~22:00 在街角长椅旁。好感到「熟人」以上，可以问她「星河或行情的事」（每天一次，风声不保证准确）；她也会教你看报表（手艺经验）。
- **城市**：奥特兰迪斯的四项指数——治安、繁荣、民心、廉洁——开局分别是 30 / 40 / 35 / 20（黑帮横行，腐败严重）。在市政厅找周慕白推动 12 个项目（路灯、夜巡、港口整治、社区诊所、夜校、公开审计……），每个要花钱、需要时间，有些还会出事。完成后指数永久改变，有的项目每天还有分成。影响力达到最高的「新生之城」会触发结局。顶部「城市」按钮随时可以看指数（只读，提案要去市政厅）。
- **口才**：所有人聊天的好感收益都会提高；Lv5 多一个专属聊天选项，Lv7 起每天每人多聊 1 次，Lv10 起好感事件奖励翻倍。
  - **好感度**（0~100）：陌生 → 认识（20）→ 熟人（40）→ 朋友（60）→ 好友（80）→ 特别的人（90）。聊天的回答选项有好有坏，送她芝士汉堡（她最爱的）加成更多。
  - 好感到 30 / 60 / 90 会触发一次性事件（一个免费汉堡、一个红包、一张速写）。好感 60 以上打工工资 +10%。
  - 好感不会无故下降；超过 3 天不去看她，之后每天 -1，但不会掉出当前称号。
- **商店（B）**：买家具、领养小猫/小狗、升级房间。买到家具后进入建造模式，点击放置，`R` 旋转，`ESC` 取消；点已摆放的家具可回收（退 50%）。
- **房间升级**：出租小屋 → 温馨一居 → 宽敞两居 → 小别墅。出租小屋需要每 7 天交房租。
- **时间与天气**：游戏内一天 = 真实 240 秒，一季 7 天，四季轮换；有昼夜、晴/雨/雪天。
- **随机事件**：快递、朋友来访、停电、捡到钱等。
- 4 项需求（精力 / 饱腹 / 心情 / 清洁）会随时间下降，任何一项归零都会有负面影响。
- 自动存档（每 20 秒，存于浏览器 localStorage）。

## 操作
| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 / 使用 / 抚摸 | 鼠标点击 | 点按 |
| 商店 | `B` | 右上角「商店」按钮 |
| 技能 | 点「技能」 | 顶部「技能」按钮 |
| 旋转家具 | `R` | 建造时下方按钮 |
| 取消放置 | `ESC` | 建造时下方按钮 |
| 暂停 | 空格 | 「暂停」按钮 |

## 运行
直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

也可部署到 GitHub Pages（Settings → Pages → main / root）。

## 代码结构
```
index.html      入口
style.css       页面样式
js/config.js    常量、家具/房间/宠物数据、状态定义与模块接口契约
js/render.js    像素绘制与画面
js/player.js    玩家移动与寻路、使用家具
js/pet.js       宠物 AI
js/economy.js   时间天气、买卖、事件、存档
js/street.js    门口外景：室内外切换、门的点击
js/npc-data.js  林小满的对话、故事、事件文案
js/npc.js       林小满：好感、聊天、送礼、故事、事件
js/burger.js    汉堡店：营业时间、买汉堡、打工
js/skills.js    技能系统：经验、升级、技能面板
js/stocks-data.js 8 只股票与城市事件数据
js/stocks.js    炒股：价格模拟、新闻、交易、股市面板
js/poker.js     德州扑克引擎、AI 对手、电脑学德扑
js/cardroom.js  牌场：首次被坑剧情、牌桌、私局
js/ui.js        HUD、商店、通用面板、建造模式、输入
js/main.js      启动与主循环
```
